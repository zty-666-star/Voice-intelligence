# Voice-intelligence：智音助手 (C3) + 语音通知中心 (P3)

本项目为《Android 移动终端应用开发技术》（2学分，主 App 选题 **C3 智能语音助手**）与《移动互联网应用开发实战》（1学分，伴生模块选题 **P3 通知提醒中心**）的完整联合工程实现。

## 一、 核心亮点与评分对照

1. **必做特色技术：自定义指令解析引擎 (`CommandRuleEngine` + `SlotExtractor`)**
   - 支持**动态正则表达式规则库**（Room 持久化，可在 UI 实时新增、编辑、启停、配置优先级）。
   - 内置**自然语言槽位抽取器 (`SlotExtractor`)**：支持中文数字与相对/绝对时间词解析（如“10秒后”、“十五分钟后”、“明天下午3点半”）、设备动作槽位抽取、四则运算槽位求解。
2. **伴生模块 P3：通知提醒中心 (`ReminderCenterActivity` + `ReminderWorker` + `NotificationActionReceiver`)**
   - 在 `AndroidManifest.xml` 中注册**独立桌面 Launcher 入口**，桌面生成「智音助手 (C3)」与「语音通知中心 (P3)」两个独立图标。
   - 使用 **WorkManager** 实现精准后台定时提醒，下拉通知栏提供 **「一键完成」** 与 **「延后5分钟」** 两个直接交互按钮（无需打开 App 即可通过广播异步更新 Room 数据库）。
3. **全面满足最低复杂度标准**
   - **5 个完整界面**：语音交互主页、规则库列表页、规则详情编辑页（标准**列表→详情**结构）、P3 伴生通知提醒中心、解析引擎数据统计看板。
   - **权限申请与优雅降级**：动态申请 `RECORD_AUDIO` 权限；当用户拒绝权限时，顶部状态栏友好提示并平滑降级为文本输入与快捷指令芯片模式，核心引擎 100% 可用。

## 二、 快速运行与录屏指引

1. 使用 Android Studio 打开本项目，等待 Gradle 同步完成。
2. 修改 `app/src/main/res/values/strings.xml` 中的 `watermark_default` 为你本人的**学号 + 姓名**（界面顶部已内置录屏水印横幅）。
3. 点击 Run 运行到模拟器或真机即可直接体验。
